# PrimeTech Solutions - Site Institucional

Projeto digital de altíssimo nível desenvolvido para a **PrimeTech Solutions**, combinando design tecnológico moderno, interatividade e alta performance.

## 🚀 Tecnologias Utilizadas
- **HTML5** (Semântico e otimizado para SEO)
- **CSS3** (Variáveis, Flexbox, Grid, Animações e Identidade Visual Neon/Cyan)
- **JavaScript Moderno** (ES6+, Intersection Observer, manipulação de DOM e integração com WhatsApp)

---

## 🛠️ Como Executar Localmente

1. Baixe ou clone este repositório em sua máquina.
2. Certifique-se de que os três arquivos principais (`index.html`, `styles.css`, `script.js`) estão na mesma pasta.
3. Abra o arquivo `index.html` diretamente em seu navegador web (Google Chrome, Firefox, Edge, Safari) ou utilize uma extensão como o **Live Server** no Visual Studio Code.

---

## 🌐 Como Publicar no GitHub e na Vercel

### Passo 1: GitHub
1. Crie uma nova conta ou acesse o [GitHub](https://github.com).
2. Crie um novo repositório público com o nome `prime`.
3. Envie (`push`) ou crie os arquivos (`index.html`, `styles.css`, `script.js`, `README.md`) na raiz do repositório.

### Passo 2: Vercel
1. Acesse a [Vercel](https://vercel.com) e faça login com sua conta do GitHub.
2. Clique em **"Add New..."** -> **"Project"**.
3. Selecione o repositório `prime`.
4. Mantenha as configurações padrão de build.
5. Clique em **Deploy**. Sua aplicação estará no ar em poucos segundos com URL segura (HTTPS) automática.
